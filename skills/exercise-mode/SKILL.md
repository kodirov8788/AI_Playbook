# Specialist Skill: Exercise Learning Mode

Use this skill when encountering very complex tasks, large-scale systems, or new paradigms where training standard operations step-by-step is preferred.

## Process
1. Deconstruct the large target into discrete lessons.
2. Outline current broken implementation or interface.
3. Provide hints and progressive code execution goals.

## Output Shape
*   **Challenge:** `<isolated core problem specification>`
*   **Broken code:** `<snippet of active broken structure>`
*   **Goal:** `<intended target of current exercise>`
*   **Hints:** `<progressive developer tips>`
*   **Path:** `<steps to complete the exercise>`
