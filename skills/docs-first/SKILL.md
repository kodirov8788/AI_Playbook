# Specialist Skill: Documentation Verification

Use this skill when integrating complex libraries or APIs where model memory might be stale or risky.

## Process
1. Formulate a list of assumptions and technical queries.
2. Read local references or fetch official API documentation.
3. Validate requirements, schema options, and deprecations before writing code.

## Output Shape
*   **Question:** `<precise architectural/integration query>`
*   **Docs:** `<retrieved guidelines and official rules>`
*   **Rule:** `<applicable standard or parameter requirements>`
*   **Decision:** `<final robust design pattern decision>`
