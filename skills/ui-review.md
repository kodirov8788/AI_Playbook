# Specialist Skill: UI & Aesthetics Audit

## Visual Standards
1. **Design System:** Use semantic CSS variables for theme consistency (colors, shadows, roundings, animations).
2. **Harmonious Palettes:** Avoid primary, raw colors (e.g., direct red, blue, green). Use HSL-tailored colors, smooth gradients, and sleek dark mode tones.
3. **Typography Scale:** Utilize modern responsive typography (e.g., from Google Fonts like Inter or Outfit) with clear hierarchy and font weights.
4. **Glassmorphism & Shadows:** Implement modern UI features (subtle borders, backdrop-filters, layered box-shadows).
5. **Micro-Animations:** Add hover transitions, active states, and spring-based animations to interactive components.
