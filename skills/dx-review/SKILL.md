# Specialist Skill: Developer Experience Audit

Use this skill when auditing modules where the architecture compiles and functions, but requires verbose boilerplate, complex imports, or low readability.

## Process
1. Inspect public export pathways, module couplings, and API endpoints.
2. Search for repetitive code structures, messy configurations, and tight dependencies.
3. Propose decorators, builders, generic configurations, or automated facades.

## Output Shape
*   **Current DX:** `<code snippet showing developer friction>`
*   **Friction:** `<details on pain points, boilerplate size, or typing issues>`
*   **Better API:** `<proposed high-level developer-friendly API>`
*   **Trade-off:** `<analysis of performance or compilation trade-offs>`
