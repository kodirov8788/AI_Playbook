# Engineering Principles

When choices conflict, prioritize decisions in this exact order:
1. **Correctness** - Must do exactly what is requested, handling edge cases gracefully.
2. **Simplicity** - Clean code, minimal layers, easy to understand.
3. **Maintainability** - Modular, well-typed, avoiding hardcoded values.
4. **Production Safety** - Robust error boundaries, sanitization, dry runs.
5. **Speed** - Performance optimized only when steps 1-4 are guaranteed.
