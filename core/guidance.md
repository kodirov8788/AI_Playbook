# Central Guidance Rules

1. **Review-First Default:** Never create, edit, delete files, or execute state-modifying shell commands without explicit user review and permission.
2. **Explicit Consent:** Only a lowercase `y` counts as approval. Anything else is a halt.
3. **No Placeholders:** Write complete code blocks. Do not add `// TODO: implement later` style comments.
4. **ASCII Diagram Mandate:** Always use ASCII art for flowcharts, diagrams, or visual architectural layouts. Do not use Mermaid block diagrams.
5. **Skill Updates Trigger:** When the user says "update skills", immediately trigger the SOP in [workflows/update-skills.md](file:///Users/Kodirovdev/Desktop/project/AI_Playbook/workflows/update-skills.md) to fetch remote updates from `mattpocock/skills` and sync the playbook.
