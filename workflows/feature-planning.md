# Workflow: Feature Planning

## Execution Phase Checklist
1. **Analyze:** Parse files, scan config states, verify dependencies, and draft a baseline design.
2. **Propose:** Create an implementation plan detailing every new and modified file.
3. **Review:** Initiate the `grill-me` routine. Identify risks, edge cases, and ask the user clarifying questions.
4. **Sign-off:** Wait for the `y` gate before making any filesystem operations.
