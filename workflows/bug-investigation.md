# Workflow: Bug Investigation

## Diagnostic Steps
1. **Capture:** Gather full error stacks, system logs, environment conditions, and user actions.
2. **Reproduce:** Execute the failing function in isolation using a test suite or runner script.
3. **Trace:** Trace the inputs to detect unexpected mutations or bad format transformations.
4. **Fix:** Plan a targeted fix addressing the root cause without altering stable secondary systems.
