# Project Bootstrapping Guide

To wire up a client project to use this playbook:

1. Create a `CLAUDE.md` in the project root.
2. Add this block to the very top:
```markdown
## AI Playbook Bootloader
Always initialize by reading the dynamic routing table:
`~/AI_Playbook/index.md`
```
3. Load the corresponding modules from the Playbook depending on the task.
