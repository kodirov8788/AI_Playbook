# Command: diagnose

## Trigger
Invoked via `/diagnose` or `diagnose`.

## Actions
1. Investigate compiler errors, build diagnostics, or stack traces.
2. Pinpoint root causes across imports, types, or syntax.
3. Output details formatted exactly as:
   - Problem: `<exact error description>`
   - Evidence: `<failing lines of code/logs>`
   - Cause: `<explanation of underlying defect>`
   - Fix path: `<proposed code edits>`
   - Risk: `<low/med/high with explanation>`
