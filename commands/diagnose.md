# Command: diagnose

## Trigger
Invoked via `/diagnose` or `diagnose`.

## Actions
1. Run target read-only execution commands to capture exact compiler errors or crash logs.
2. Outline findings under:
   - **Problem:** [Error logs and symptoms]
   - **Evidence:** [File lines and variables inspected]
   - **Cause:** [Root cause explanation]
   - **Fix Path:** [Step-by-step refactoring candidates]
   - **Risk:** [Impact level]
